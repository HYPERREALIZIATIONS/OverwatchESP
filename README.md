ESPOverwatch – External Overlay ESP

Usage:
1. Start Overwatch in Borderless Windowed mode.
2. Run ESPOverwatch.exe as Administrator.
3. Press F1 to toggle ESP on/off.

Note: If offsets change after a game update, update the signatures in memory.cpp.
The program will fail gracefully if patterns are not found.

Build:
- Open ESPOverwatch.vcxproj in VS2022 and build Release x64.
- Or run compile.bat (requires MSVC in PATH).
